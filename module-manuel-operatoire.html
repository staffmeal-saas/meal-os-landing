Questions

Avant de vous lancer.

J'ai déjà mes procédures sur papier.+

On les reprend avec vous pendant le paramétrage. Une procédure courte se saisit en quelques minutes.

Qui peut modifier une procédure ?+

La direction. L'équipe lit et peut proposer une modification, qui n'est publiée qu'après validation.

Ça marche pour plusieurs établissements ?+

Oui. Une procédure créée pour le groupe se retrouve sur tous les sites, chaque site peut avoir les siennes en plus.
