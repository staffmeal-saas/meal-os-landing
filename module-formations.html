Questions

Avant de vous lancer.

Je dois écrire toutes les formations ?+

Vous les créez dans l'éditeur, module par module. Pendant la bêta, on construit les premières avec vous.

Ça se fait pendant le service ?+

Non, en dehors. Un module prend quelques minutes, sur le téléphone de l'équipier.

Et si quelqu'un échoue au quiz ?+

Il relit la leçon et retente, dans la limite que vous avez fixée. Le manager voit qui bloque.
